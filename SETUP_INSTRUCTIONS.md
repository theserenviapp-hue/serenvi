## 🆘 Troubleshooting

**"Docker not installed"**
→ Download from https://docker.com/products/docker-desktop

**"Port 5432 in use"**
→ Run: `docker stop serenvi_db && docker rm serenvi_db`

**"npm install fails"**
→ Run: `npm cache clean --force && npm install`

**"Can't connect to database"**
→ Run: `docker logs serenvi_db`

**More help:** See [LOCAL_SETUP.md](./LOCAL_SETUP.md)
